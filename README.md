# Mestrados Abertos – Geografia

Painel simples com os editais de Mestrado em Geografia: prazos, vagas, exigências do projeto, critérios, linhas de pesquisa e orientadores. Tudo no mesmo formato para facilitar a comparação.

Programas atuais: UFS, UNICAMP, UFU e UFT.

## Como usar
- **Localmente:** abra o `index.html` no navegador.
- **Na internet (grátis):** no GitHub, vá em *Settings > Pages*, escolha a branch `main` e a pasta `/ (root)`. O site fica em `https://SEU-USUARIO.github.io/NOME-DO-REPO/`.

## Estrutura
- `index.html`: a página (busca, filtro por situação e tabela comparativa).
- `data/programas.js`: os dados. É o único arquivo que você precisa editar.
- `CONTRIBUTING.md`: como adicionar ou corrigir um edital.

## Aviso
Os dados são compilados dos editais e podem mudar. Confira sempre no edital oficial.
