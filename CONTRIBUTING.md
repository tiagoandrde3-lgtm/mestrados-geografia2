# Como contribuir

1. Abra `data/programas.js`.
2. Para **corrigir**, edite o campo e atualize `atualizado`.
3. Para **adicionar** um programa, copie um bloco inteiro (de `{` até `},`), cole no fim da lista e troque os dados. Use um `id` novo.
4. Datas de inscrição no formato `AAAA-MM-DD` (a situação Aberta/Em breve/Encerrada é calculada sozinha).
5. Preencha `url` com o link do edital oficial. Não coloque dados sem fonte.
6. Abra um Pull Request descrevendo o que mudou.

Este painel cobre apenas Mestrado.
